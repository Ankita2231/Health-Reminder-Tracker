# Health Reminder & Tracker

## SDG Selected
SDG 3: Good Health and Well-Being

## Problem Statement
Many people forget to take medicines, exercise regularly, and drink enough water. This can negatively affect their health and well-being.

## Project Objective
To help users maintain healthy habits through reminders and tracking.

## Features
- Water Intake Tracker
- Exercise Tracker
- Medicine Reminder
- Health Dashboard

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download the project.
2. Open the folder in VS Code.
3. Open index.html using Live Server.

- Mobile Application
